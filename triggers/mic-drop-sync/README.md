# Mic Drop Sync

Keeps Tuple's mute in sync with [Mic Drop](https://getmicdrop.com/)'s global mute on Mac, so others see an accurate mute status.

When you join a call or room, Tuple's mute is set to match Mic Drop.

During the call, muting or unmuting in either app updates the other.

On first run, macOS will ask whether TupleTriggers may control Mic Drop. Allow it.

See `DEVELOPMENT.md` for details.
